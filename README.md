⚖️ Calculadora de IMC

Projeto desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, utilizando HTML, CSS e JavaScript.

📌 Sobre o projeto

Uma calculadora de Índice de Massa Corporal (IMC) que recebe o peso e a altura do usuário, realiza o cálculo e apresenta o resultado com sua classificação.

🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
💻 Funcionalidades
Entrada de peso e altura
Cálculo automático do IMC
Exibição do resultado
Classificação do IMC
Interface responsiva
🚀 Como executar
Baixe ou clone este repositório.
Abra o arquivo index.html no navegador.
Informe seu peso e sua altura.
Clique em Calcular IMC.
📚 Objetivo

Projeto desenvolvido para praticar conceitos de HTML, CSS e JavaScript, principalmente manipulação de elementos da página e interação com o usuário.
